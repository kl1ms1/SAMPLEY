# SAMPLEY — идеи фишек

Что ещё можно добавить. Сложность: 🟢 — только софт, пара вечеров; 🟡 — софт
посерьёзнее; 🔴 — нужно железо.

## Звук и эффекты

| | Фишка | Что это |
|---|---|---|
| 🟢 | **Tape stop** | Кнопка — музыка «тормозит», как выдернутый из розетки магнитофон: тон и скорость падают до нуля. Отпустил — разгоняется обратно |
| 🟢 | **Лоу-фай / биткрашер** | Крутилка «старости»: 12 бит, 26 кГц, шипение винила — звук как у сэмплеров 90-х |
| 🟢 | **Дилей и реверб** | Эхо в темп (1/8, 1/4 с точкой) и «комната». На шаге секвенсора можно включать эхо только на одном ударе |
| 🟢 | **Ресемплинг** | Записать то, что сейчас играет SAMPLEY, прямо на пустой пэд — со всеми эффектами, скретчем и STUTTER. Потом этот кусок опять резать CHOP-ом |
| 🟡 | **Растяжение без смены тона** | Луп с улицы подгоняется под темп бита, но голос не становится «бурундуком» |
| 🟡 | **Автотемп** | Записал луп — SAMPLEY сам определил его темп и предложил разрезать ровно по долям |
| 🟢 | **Лад для 16 LEVELS** | Пэды играют только ноты выбранного лада (минор, мажор, пентатоника) — мелодия всегда звучит «правильно» |
| 🟢 | **Аккорды** | Один пэд — сразу аккорд из сэмпла (минор, мажор, септ), как в хип-хоп битах |

## Секвенсор

| | Фишка | Что это |
|---|---|---|
| 🟢 | **Песня** | Цепочка паттернов: A, A, B, A, C… — собрать трек целиком |
| 🟢 | **Вероятность шага** | Шаг играет не всегда, а, скажем, в 70 % случаев — бит «живой», не повторяется |
| 🟢 | **Дробь на шаге** | На одном шаге 2–4 удара (как хэты в трэпе) |
| 🟢 | **Запись вертушки** | Скретч записывается в паттерн и повторяется сам |
| 🟢 | **Отмена (UNDO)** | SHIFT + STOP — вернуть, что случайно стёр |
| 🟢 | **Метроном и отсчёт** | «Раз-два-три-четыре» перед записью |

## Связь

| | Фишка | Что это |
|---|---|---|
| 🟢 | **Закинуть звуки с телефона по Wi-Fi** | SAMPLEY показывает адрес, открываешь его на телефоне — страничка: перетащил WAV/MP3, он появился в BROWSE. Обратно — скачать свой бит |
| 🟢 | **MIDI по USB** | Подключил к компьютеру — SAMPLEY это MIDI-контроллер с пэдами и вертушками (FL Studio, Ableton) |
| 🟡 | **Ableton Link по Wi-Fi** | Темп сам совпадает с другими SAMPLEY, телефонами и Ableton в той же сети — джем вдвоём |
| 🟡 | **Bluetooth-наушники** | Без провода (задержка будет больше — для прослушки, не для игры) |
| 🟢 | **Бит в WAV одной кнопкой** | Сохранить весь трек в файл, скинуть в Telegram через страничку Wi-Fi |

## Железо

| | Фишка | Что это |
|---|---|---|
| 🔴 | **Гироскоп** | Наклоняешь девайс — фильтр или STUTTER «едет». Чип за 1 $, очень эффектно на видео |
| 🔴 | **Беспроводная зарядка Qi** | Положил на зарядку телефона — заряжается |
| 🔴 | **Вибро-отклик** | Лёгкий «тук» на каждую долю в руку — чувствуешь темп без звука |
| 🔴 | **Светодиоды по кругу вертушек** | Кольцо светится и бежит в темп, показывает позицию «пластинки» |
| 🔴 | **Pressure-пэды с послезвучием** | Давишь сильнее после удара — звук меняется (фильтр, тон). Датчики силы уже стоят, нужен только софт — 🟢 |
