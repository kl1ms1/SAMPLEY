# Этап 1 — макетка из готовых модулей

Цель: собрать работающий сэмплер **без своей платы**, проверить звук,
задержку, пэды, энкодеры и питание. Всё, что тут проверим, потом
переносится на плату один в один (те же чипы, те же пины, тот же софт).

Что купить — [`shopping-list.md`](shopping-list.md), раздел «Макетка».

## Схема макетки

```
  Pi Zero W/2W ── шлейф 40 pin ── T-Cobbler на макетной плате
     │
     └─ снизу UPS-Lite (аккумулятор, зарядка, защита — пока готовый)

  С макетной платы проводами:
     → Waveshare WM8960 Audio HAT   (9 проводов, папа-мама в его гнездо)
     → экран 2.0″ ST7789            (8 проводов)
     → Raspberry Pi Pico            (UART + 5 В + GND + GPIO26)
            → силиконовый пэд 4×4 (SparkFun), 15 кнопок, 3 энкодера + колесо EC11, фейдер, ручка громкости, WS2812
```

## Pi ↔ WM8960 Audio HAT

HAT втыкать прямо в Pi нельзя — тогда гребёнка занята. Подключаем
проводами в его гнездо (номера — физические пины гребёнки, у HAT такие же):

| Пин | Сигнал | |
|---|---|---|
| 2 | 5 В | питание усилителя динамиков |
| 1 | 3.3 В | |
| 6 | GND | |
| 3 | GPIO2 SDA | I2C |
| 5 | GPIO3 SCL | I2C |
| 12 | GPIO18 BCLK | I2S |
| 35 | GPIO19 LRCLK | I2S |
| 38 | GPIO20 DIN | запись (кодек → Pi) |
| 40 | GPIO21 DOUT | звук (Pi → кодек) |

## Pico ↔ кнопки, крутилки, фейдер, подсветка

**Матрица 6×6.** Строки GP2…GP7, столбцы GP8…GP13.

| | GP8 | GP9 | GP10 | GP11 | GP12 | GP13 |
|---|---|---|---|---|---|---|
| **GP2** | пэд 1 | пэд 2 | пэд 3 | пэд 4 | нажатие K1 | SHIFT |
| **GP3** | пэд 5 | пэд 6 | пэд 7 | пэд 8 | нажатие K2 | PLAY |
| **GP4** | пэд 9 | пэд 10 | пэд 11 | пэд 12 | нажатие K3 | STOP |
| **GP5** | пэд 13 | пэд 14 | пэд 15 | пэд 16 | нажатие колеса | REC |
| **GP6** | SAMPLE | STEP | CHOP | MUTE | MODE | LEVELS |
| **GP7** | BANK | REPEAT | TAP | BROWSE | KITS | — |

Силиконовый пэд 4×4 (плата SparkFun Button Pad Breakout): её 4 вывода строк (SWT-GND) → GP2…GP5, 4 вывода столбцов (SWITCH) → GP8…GP11; светодиоды на этой плате не ставим — подсветку даёт WS2812.
Остальные кнопки и кнопки энкодеров — между строкой и столбцом, как в
таблице. Диоды 1N4148 (катод — полоска — к строке) нужны, чтобы правильно
читались 3+ одновременных нажатия; для первого запуска можно без них.
Для начала хватит части кнопок: SHIFT, PLAY, STOP, REC, SAMPLE, CHOP —
остальные добавишь потом, прошивку менять не надо.

**Энкодеры EC11** (голые, 5 ног): средняя нога из трёх (C) — на GND,
крайние A/B → K1: GP14/15, K2: GP16/17, K3: GP18/19, колесо: GP20/21.
Крутится «не в ту сторону» — поменяй A и B. Две ноги кнопки — в матрицу.

**Фейдер и ручка громкости** (потенциометры 10 кОм, линейные): крайние
выводы — на 3V3(OUT) (пин 36 Pico) и AGND (пин 33), средний — фейдер на
GP26, громкость на GP27.

**Подсветка WS2812** (матрица 4×4 = пэды; ещё 15 штук ленты — под кнопки,
можно потом): DIN → GP22, питание 5 В от Pi, GND общий. Яркость в прошивке
ограничена (35 %) — от Pi хватает тока.

## Питание на макетке

**UPS-Lite v1.3** под Pi Zero: держит аккумулятор, заряжает, защищает,
поднимает 5 В. SAMPLEY сам находит его датчик заряда (CW2015) и показывает
проценты на экране. Ползунок и «защёлку» на макетке не делаем — в прошивке
Pico `POWER_CONTROL = False`. Своё управление питанием (BQ25895 + ползунок)
появится на плате.

## Установка софта

1. Raspberry Pi Imager → **Raspberry Pi OS Lite (32-bit)** — подходит и Zero W, и Zero 2 W.
   В настройках Imager включить SSH и Wi-Fi.
2. На Pi:
   ```bash
   sudo apt install -y git
   git clone https://github.com/kl1ms1/SAMPLEY
   cd SAMPLEY/software && sudo ./install.sh
   sudo reboot
   ```
3. Громкость и вход кодека: `alsamixer` (F6 → wm8960): поднять Headphone,
   Speaker, включить Left/Right Boost Mixer для микрофона. Сохранить:
   `sudo alsactl store`.
4. Pico: Thonny → Установить MicroPython → открыть `firmware/pico/main.py` →
   «Сохранить как» на Raspberry Pi Pico под именем `main.py`.

После перезагрузки SAMPLEY запускается сам. Логи: `journalctl -u sampley -f`.

## Что проверить на макетке

- [ ] Звук из наушников и динамиков, без треска при 8+ звуках сразу
- [ ] Задержка пэд → звук на слух нормальная (Zero 2 W)
- [ ] Запись с микрофона и с линейного входа
- [ ] Энкодеры не пропускают щелчки при быстром вращении
- [ ] CHOP: записать улицу, порезать, сыграть бит
- [ ] Фейдер: тон и фильтр плавные, без треска
- [ ] Подсветка пэдов: цвет и яркость нравятся
- [ ] Экран читается на улице
- [ ] Сколько реально живёт от аккумулятора (минимум 2 часа на UPS-Lite)
- [ ] Выбрать силиконовые пэды и их размер для платы
