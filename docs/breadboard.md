# Этап 1 — макетка из готовых модулей

Цель: собрать работающий сэмплер **без своей платы**, проверить звук,
задержку, пэды, энкодеры и питание. Всё, что тут проверим, потом
переносится на плату один в один (те же чипы, те же пины, тот же софт).

Что купить — [`shopping-list.md`](shopping-list.md), раздел «Макетка».

## Схема макетки

```
  Pi Zero W/2W ── шлейф 40 pin ── T-Cobbler на макетной плате
     │
     └─ снизу UPS-Lite (аккумулятор, зарядка, защита — пока готовый)

  С макетной платы проводами:
     → Waveshare WM8960 Audio HAT   (9 проводов, папа-мама в его гнездо)
     → экран 2.0″ ST7789            (8 проводов)
     → Raspberry Pi Pico            (UART + 5 В + GND + GPIO26)
            → 16 датчиков FSR (пэды), 16 кнопок, 2 вертушки, энкодеры, фейдер, громкость, WS2812
```

## Pi ↔ WM8960 Audio HAT

HAT втыкать прямо в Pi нельзя — тогда гребёнка занята. Подключаем
проводами в его гнездо (номера — физические пины гребёнки, у HAT такие же):

| Пин | Сигнал | |
|---|---|---|
| 2 | 5 В | питание усилителя динамиков |
| 1 | 3.3 В | |
| 6 | GND | |
| 3 | GPIO2 SDA | I2C |
| 5 | GPIO3 SCL | I2C |
| 12 | GPIO18 BCLK | I2S |
| 35 | GPIO19 LRCLK | I2S |
| 38 | GPIO20 DIN | запись (кодек → Pi) |
| 40 | GPIO21 DOUT | звук (Pi → кодек) |

## Pico ↔ пэды, кнопки, вертушки, крутилки, подсветка

Прошивка v3 (`firmware/pico/main.py`). Ноги Pico:

| Pico | Что |
|---|---|
| GP2…GP5 | S0…S3 мультиплексора 74HC4067 (пэды) |
| GP28 (АЦП2) | SIG мультиплексора — сила нажатия пэда |
| GP6 / GP7 / GP8 | 74HC165: SH/LD, CLK, QH — все кнопки по 3 проводам |
| GP9/10, 11/12, 13/14 | энкодеры K1, K2, K3 (A/B) |
| GP17 | данные подсветки WS2812 (эффекты считает сам Pico) |
| GP18/19 | I2C1 SDA/SCL — AS5600 левой вертушки |
| GP20/21 | I2C0 SDA/SCL — AS5600 правой вертушки |
| GP26 (АЦП0) | фейдер |
| GP22 | ползунок питания (на макетке не нужен) |

**Пэды с силой удара.** На макетке под каждый пэд — датчик давления FSR402
(круглый, 18 мм), сверху — силиконовая накладка. Одна нога каждого датчика
на 3V3, другая — на свой вход C0…C15 мультиплексора, и каждый вход ещё
через 10 кОм на GND. Общий выход SIG → GP28. Жмёшь сильнее — громче звук.
Пороги подстраиваются в начале прошивки (`PAD_ON`, `PAD_FULL`;
`DEBUG_PADS = True` печатает, что видит каждый пэд).

**Кнопки — через 3 × 74HC165** (сдвиговые регистры, цепочкой: QH второго
→ SER первого и т. д.). Каждая кнопка — между входом регистра и GND,
вход подтянут 10 кОм к 3V3 (удобно сборкой резисторов). Порядок входов —
список `BUTTON_INPUTS` в прошивке: SHIFT, PLAY, STOP, REC, SAMPLE, STEP,
CHOP, MUTE, MODE, LEVELS, BANK, REPEAT, TAP, BROWSE, KITS, STUTTER,
нажатия K1, K2, K3, (запас), касание левой и правой вертушки.

**Вертушки.** Диск на подшипнике, в центре оси — магнит, под ним модуль
AS5600 (4096 точек на оборот, ничего не трётся). Сенсор касания TTP223 —
провод от металлической верхней пластины диска на его вход; выход TTP223 —
на вход 74HC165 (касание = 0). Для начала хватит одной вертушки, вторая
может быть не подключена — прошивка её просто пропустит.

**Энкодеры без щелчков** (EC11 без фиксации): средняя нога из трёх (C) —
на GND, A/B — как в таблице. Крутится «не в ту сторону» — поменяй A и B.

**Фейдер** (10 кОм, линейный): крайние выводы — на 3V3(OUT) (пин 36) и
AGND (пин 33), средний — на GP26.

**Подсветка WS2812** (16 под пэды + 16 под кнопки, можно начать с 16):
DIN → GP17, питание 5 В от Pi, GND общий. Яркость ограничена (35 %).

## Питание на макетке

**UPS-Lite v1.3** под Pi Zero: держит аккумулятор, заряжает, защищает,
поднимает 5 В. SAMPLEY сам находит его датчик заряда (CW2015) и показывает
проценты на экране. Ползунок и «защёлку» на макетке не делаем — в прошивке
Pico `POWER_CONTROL = False`. Своё управление питанием (BQ25895 + ползунок)
появится на плате.

## Установка софта

1. Raspberry Pi Imager → **Raspberry Pi OS Lite (32-bit)** — подходит и Zero W, и Zero 2 W.
   В настройках Imager включить SSH и Wi-Fi.
2. На Pi:
   ```bash
   sudo apt install -y git
   git clone https://github.com/kl1ms1/SAMPLEY
   cd SAMPLEY/software && sudo ./install.sh
   sudo reboot
   ```
3. Громкость и вход кодека: `alsamixer` (F6 → wm8960): поднять Headphone,
   Speaker, включить Left/Right Boost Mixer для микрофона. Сохранить:
   `sudo alsactl store`.
4. Pico: Thonny → Установить MicroPython → открыть `firmware/pico/main.py` →
   «Сохранить как» на Raspberry Pi Pico под именем `main.py`.

После перезагрузки SAMPLEY запускается сам. Логи: `journalctl -u sampley -f`.

## Что проверить на макетке

- [ ] Звук из наушников и динамиков, без треска при 8+ звуках сразу
- [ ] Задержка пэд → звук на слух нормальная (Zero 2 W)
- [ ] Запись с микрофона и с линейного входа
- [ ] Энкодеры не пропускают щелчки при быстром вращении
- [ ] CHOP: записать улицу, порезать, сыграть бит
- [ ] Фейдер: тон и фильтр плавные, без треска
- [ ] Вертушка: скретч без «ступенек», касание ловится сразу
- [ ] STUTTER: «а-а-а-а» ровно в темп, разгон вертушкой
- [ ] Сила удара: тихо/громко получается по желанию
- [ ] Подсветка пэдов: цвет и яркость нравятся
- [ ] Экран читается на улице
- [ ] Сколько реально живёт от аккумулятора (минимум 2 часа на UPS-Lite)
- [ ] Выбрать силиконовые пэды и их размер для платы
